# NoA releases

Signed and notarized builds of NoA, a calmer browser for macOS. Download the newest one from [noa.kevbry.in](https://noa.kevbry.in), or pick a DMG from [Releases](https://github.com/kevicebryan/noa-releases/releases):

- `NoA-arm64.dmg` for Apple Silicon Macs (M1 and later).
- `NoA-x64.dmg` for Intel Macs.

NoA tells you when a newer version is out. To report a bug, use Help > Copy Diagnostics for a Bug Report and send the text to the maintainer.

This repository holds builds only.
